## 桌面与任务栏

- [x] 桌面以壁纸为主，Win10 风格系统表面使用方角；Start 使用壁纸加白色遮罩
- [x] 任务栏图标默认居中；托盘集中右侧，整体入口感强于零散小图标
- [x] Start 与 Task View 在中央区域逻辑中
- [x] 打开应用时中间图标平滑让位
- [x] 固定应用与未固定运行应用有分隔
- [x] 支持 small / medium / large 任务栏尺寸（large 面向触控）
- [x] 平板：任务栏任意位置上滑打开 Start（不依赖点中 Start 小图标）
- [x] 应用图标左键/轻触按未运行→启动、当前活动→最小化、已最小化或其他已运行应用→恢复/切换；从 Start/无活动窗口恢复时以 flutter_metro_ui 的 200ms `easeOutQuad` 快照从任务栏图标放大，两个活动应用间切换时用 500ms 旧页后撤＋新页横向滑入并放大；全屏动画使用输出宽高各 25% 的独立快照，不放大任务栏缩略图；多窗口轮流抓取，缩放、PNG 压缩与写盘在有界后台线程完成，不阻塞合成器主渲染；右键或在图标上上滑打开应用菜单，可关闭、固定/取消固定、开启新窗口、分屏或切换浮动窗口，固定项持久化
- [x] 应用切换动画可独立关闭并持久化；关闭后不创建 shell 切换代理，也不做后台 GPU 截图读取或 PNG 编码，仅在用户打开多窗口任务栏菜单时按需生成有界小缩略图
- [x] 同一应用存在多个真实窗口时，应用菜单逐一显示窗口内容缩略图、标题和当前活动边框；点击缩略图只置顶并聚焦对应窗口
- [x] 悬停缩略图仅作指针增强，触控主流程不依赖

## Launcher

- [x] 顶部统一搜索（应用 / 文件 / Web 能力可分阶段）— MVP：本机应用名过滤
- [x] Windows 10 平板式全屏开始屏幕：应用列表、固定应用与 Live Tiles（用户明确要求的 Win10X 混合设计）
- [x] Start 布局样式可选择并持久化：Windows 10 为左侧应用列表＋右侧纵向滚动磁贴板；Windows Phone 为仅磁贴的纵向滚动主页，左滑后以 340ms `easeOutExpo` 非线性横向推页进入应用列表、右滑返回；Windows 8 严格沿用 flutter_metro_ui 的 `#1d1d1d` 页面、可切换的 120px 普通/250px 宽磁贴、10px 间距、100px 左/140px 上边距、最多六行且按列优先的横向 Metro 布局，并按真实磁贴组分别使用 1.05s 起、后组逐组延迟 120ms 的入场及 1.5s 延迟标题动画；向上滑或点左下角按钮后以同样 340ms 非线性纵向推页进入横向应用列表，向下滑返回
- [x] 三种 Start 布局共用并持久化磁贴分组：磁贴菜单可移动到已有组或建立新组；单击/轻触组标题或右键选择“重命名”会进入稳定的内联编辑，Enter/失焦保存、Escape 取消；Windows 10/Phone 排列时保留组间隔，Windows 8 将各组横向独立排布并围绕各自中心成组入场，其磁贴拖动与 Win10/Phone 一致：8epx 激活阈值、浮动跟手、基于拖拽前快照的实时让位预览，按落点重排并可跨组移动，落点永远吸附到最近组，松手以回弹动画落格
- [x] Start 背景整屏淡变到「壁纸 + 半透明白色层」，不做自下而上铺开，也暂不做亚克力模糊
- [x] Start 屏幕动画可在设置中独立选择并持久化：默认 Windows 10 Mobile 底部行波动（同一行黏合为一层、91%→100% 并向下落位，上层逐层向下方磁贴贴合，整段 ≤0.40s），另有 Disco turnstile、Metro 上浮淡入、Factor 滑入缩放和 flutter_metro_ui「每个真实磁贴组从右侧 100epx、80% 缩放与 0 透明度以 `easeOutExpo` 成组进入，后组逐组错开」；每套样式都与背景同时完成
- [x] 应用启动动画有独立设置并持久化：Windows 10 Mobile 从完整 100% 磁贴布局开始、所有磁贴整行掀起并由上到下淡出（被点击磁贴比所属行晚 0.08s，但同样消失，不放大到全屏），应用列表、侧栏与搜索同时渐隐；内容清空后只保留开始屏幕的壁纸＋白色遮罩背景 0.20s 等待应用启动；另有 Windows 8「开始屏幕整体后撤＋点击磁贴悬空放大、翻面并铺满屏幕」、Disco 按点击来源翻出、Factor 从点击区域展开、Metro/系统默认；点击当帧立即启动进程并同步播放动画，以覆盖冷启动等待
- [x] 拖动磁贴时，发生碰撞的磁贴只在原位周围平滑避让；拖动磁贴移开后，临时避让的磁贴会回到拖拽开始前的位置
- [x] 「全部应用」展开
- [x] 下部最近活动 / 最近文件
- [x] 电源与账户不在 Launcher，而在 Action Center 底部区域

## 窗口与姿态

- [x] 完整嵌套会话中，应用连接 `win10x-comp` 而非宿主桌面，并以 Wayland `Fullscreen` 状态占满整个输出；任务栏/面板由透明 shell 覆盖在应用上方
- [x] 透明 shell 仅在任务栏/已打开面板区域接收输入，桌面区域的指针与触摸会穿透到最上层应用；任务栏与 Task View 由合成器的真实 xdg 窗口列表驱动，点击条目激活已有窗口而非再次启动应用
- [x] 合成器管理全屏、最小化、左右分屏和 72% 居中浮动布局；无客户端标题栏的浮动窗口仍可用鼠标或触摸从顶部 36 epx 拖动，拖动时 shell 任务栏保持在最上层
- [x] Task View 可用触控完成切换
- [x] 横竖屏、窄屏下核心 UI 仍可用 — shell 含 orientation demo
- [ ] 软键盘弹出时，活动输入框不被遮挡（内容/容器带动画上移）— **完整版**（MVP 仅有 inset 钩子）
