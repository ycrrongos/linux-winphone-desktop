# Windows 10X UI / Interaction Research Archive

本目录收集与本项目（面向触屏手机的 Windows 10X 风格 Linux 桌面）相关的公开资料。当前主目录只放单屏版本优先使用的资料。

## 目录

- `pages/`：来源网页本地快照目录（HTML 快照已从仓库移除，避免再分发受版权保护的网页副本；请按 `sources.tsv` 访问原链接）。
- `images/`：来源图索引目录（截图文件已从仓库移除；URL 仍见 `images/image-sources.tsv`）。
- `notes/`：中文整理、交互逻辑摘要与来源索引。
- `sources.tsv`：机器可读的来源清单。
- `dual-screen-hardware/`：暂缓使用的双屏/折叠硬件、铰链、跨屏布局及 Wonder Bar 资料。

## 说明

- Windows 10X 最初面向双屏/折叠设备，后来转向单屏设备，最终取消发布。双屏硬件资料已独立归档，当前研究以单屏泄漏版本和可复用的系统 UI 为主。
- 本项目面向手机触屏，因此整理时优先关注触控目标、底部任务栏、上滑启动器、快速设置、通知、窗口切换、屏幕姿态与软键盘。
- 网页和图片版权归原作者或发布方所有，仅作为项目设计研究资料。仓库只保留文字笔记与来源索引，不存放也不再分发受版权保护的截图、商标图或整页 HTML 快照。
