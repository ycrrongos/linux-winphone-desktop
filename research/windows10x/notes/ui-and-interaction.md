# Windows 10X UI 与操作逻辑资料整理

整理日期：2026-08-12。这里记录的是资料事实与观察，不是实现方案。

## 1. 资料版本边界

Windows 10X 从未正式发布，公开画面主要来自三个阶段：

1. 2019 年微软双屏概念演示。
2. 2020 年 Windows 10X Emulator 开发者预览。
3. 2021 年泄漏的单屏构建：更接近微软后来面向轻量单屏 PC 的方向，但仍不是正式产品。

本目录当前以第 3 阶段及可复用于单屏的系统 UI 为主。前两个阶段涉及的双屏硬件、铰链、跨屏和 Wonder Bar 资料已移至 `../dual-screen-hardware/`，暂不进入单屏版本的研究范围。

## 2. 高置信的视觉语言

- 桌面以壁纸和极少量常驻元素为主，系统表面使用浅色或深色的浮动卡片。
- 面板和窗口大量使用圆角、阴影、留白与分组；视觉密度显著低于传统 Windows 10。
- Segoe 风格排版，彩色现代应用图标；常用动作以图标配短标签呈现。
- 任务栏图标默认居中，系统托盘集中在右侧；系统托盘更像一个整体入口而非大量独立小图标。
- 动画强调连续性：应用启动后图标让位、最小化时图标轻微弹跳、面板从触发位置自然出现。

## 3. Launcher（开始菜单）

开发者预览版中，开始菜单被重新组织为一个居中的 Launcher：

- 顶部是统一搜索，可查应用、文件和 Web。
- 中部是固定应用网格，不再使用 Live Tiles。
- “Show all”/展开动作进入全部应用。
- 下部是最近活动或最近文件，强调继续工作而非只负责启动应用。
- 电源和用户账户入口从开始菜单移到了 Action Center 底部区域，降低 Launcher 的功能混杂。

Windows Central 的总览还记录了平板状态下“在任务栏任意位置上滑即可打开 Start”的行为；这对触屏设备很关键，因为它不要求命中一个小型 Start 图标。

对应资料：S05、S09；图片见 `start-*.jpg`。

## 4. 任务栏与应用切换

- Start 与 Task View 位于中央，固定应用与运行应用分组排列。
- 打开应用时，中间图标会平滑移动并为新运行项腾出位置。
- 固定应用和非固定运行应用之间存在分隔，帮助理解状态。
- 预览资料展示过 small / medium / large 三种任务栏尺寸；large 针对平板/触控。
- 早期构建保留过经典左对齐选项，说明布局被设计为可适应输入方式和形态。
- 悬停缩略图属于鼠标增强行为，触屏主流程不能依赖悬停。

对应资料：S05、S09；图片见 `taskbar-*.jpg`。

## 5. Action Center：通知与快速设置

Windows 10X 把系统状态入口重做为多个层次清楚的卡片：

- 通知位于上方独立面板，按应用分组，并提供 Clear all。
- 媒体播放时出现专用媒体控制卡片。
- 快速设置位于下方，可在面板内继续展开 Wi-Fi、Bluetooth、辅助功能等二级选项，而不是每次跳转到 Settings。
- 电池百分比、设置入口、电源、用户头像/锁定/退出等被放在面板底部。
- 点击用户头像后出现锁定和退出等账户操作。

这种逻辑把“高频、短时、可原地完成”的系统操作保留在浮层内，把完整配置留给 Settings。

对应资料：S06、S09；图片见 `action-center-*.jpg`。

## 6. 文件管理器

- Windows 10X 的现代 File Explorer 更轻量、触控友好，围绕 OneDrive 与本地常用位置组织。
- 支持浅色/深色外观，并显示同步状态。
- 早期版本能力不完整；资料曾一度误判只能管理 OneDrive，后续确认也可浏览本地文件。
- Windows 10X 早期 Win32 容器仍可能出现经典文件选择器，因此截图中的一致性不能视为最终承诺。

对应资料：S07、S09；图片见 `file-explorer-*.jpg`。

## 7. OOBE、锁屏与软键盘

- 首次设置采用大字号、宽松间距、居中内容和清晰的单步流程。
- Cortana 不再主导安装流程。
- OOBE 期间仍可从右下角进入音量和输入语言等必要快速设置。
- 微软当前触控指南强调：小屏设备的软键盘可能占用约一半屏幕；激活的文本框不可被键盘遮挡，必要时内容或容器应带动画上移。

对应资料：S08、S09、S12；图片见 `oobe-*.jpg`。

## 8. 对手机触屏研究最相关的硬指标

这些数值来自微软当前 Windows 触控指南，不是 Windows 10X 专属尺寸：

- 基本可触目标至少约 40 × 40 epx。
- 触控优先 UI 可考虑 44 × 44 epx，目标之间至少 4 epx 可见间距。
- 高频或误触后果严重的操作应更大，并远离边缘或其他危险操作。
- 横屏、竖屏和窄窗口都应保持核心 UI 可用。
- 不把 hover 作为唯一入口；触摸需要即时、跟手、可见的反馈。
- 标准手势应保持标准含义；破坏性误操作应当可撤销或易于纠正。

对应资料：S12、S13。

- 通知为空/多条/分组、快速设置一级/二级、媒体播放、电源/账户菜单。
