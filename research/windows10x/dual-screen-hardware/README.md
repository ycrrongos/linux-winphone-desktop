# 双屏/折叠硬件资料

这里集中存放依赖双屏或折叠硬件的 Windows 10X 资料。几何与 Wonder Bar 已在
Flutter shell（`dual_screen.dart` / `wonder_bar.dart`）按本目录笔记落地；
真机多输出 / 跨应用拖放仍依赖主机 compositor 接线。

包括：

- Surface Neo / Surface Duo 等双屏设备姿态。
- 铰链与遮挡区域。
- 窗口跨屏、跨应用拖放和双屏模拟器操作。
- Extended Canvas、List–Detail、Two Page、Companion Pane、Dual View。
- 硬件键盘占据部分屏幕后出现的 Wonder Bar。

网页与图片版权归各发布方所有，仅用于设计研究。仓库已移除本目录下的 HTML 快照与截图文件；来源链接保留在 `sources.tsv` 与 `images/image-sources.tsv`。
